# Extension Ideas

Extensions are optional. Add them only after the MVP is stable and benchmarkable.

## Model Extensions

- Von Neumann versus Moore neighbourhood comparison.
- Graph topologies using adjacency lists.
- Probabilistic action noise.
- Resource or energy field.
- Reputation/trust value per agent.
- Asynchronous update mode in Python.

## Strategy Extensions

- User-programmable finite-state strategies via DSL or JSON/YAML rules.
- Suspicious Tit-for-Tat.
- Generous Tit-for-Tat.
- Grudger.
- Epsilon-greedy adaptive strategy.
- Parameter sweeps for Random(p) and mutation probability.

## Exploratory Platform Extensions

- Safe parser/validator for user strategies.
- Strategy compiler from FSM rules to packed LUTs.
- Arena mode for user-submitted strategy tournaments.
- Spatial invasion experiments with user strategies.
- Frame/video export for strategy dynamics.
- Benchmark suites against fixed reference strategies.

## Hardware Extensions

- Replicated update engines.
- Tiled streaming with halo cells.
- Hardware statistics reducer.
- Runtime-selectable payoff matrix.
- Separate resource-field update pipeline.

## Visualisation Extensions

- Web dashboard.
- Side-by-side CPU/FPGA playback.
- Payoff and cooperation timelines.
- Cluster-size analysis.
- Replay files for presentation.
- Export `frame_0000.png` sequences and `evolution.mp4`.

## Distributed Extensions

- Multi-board grid partitioning.
- Ethernet border exchange.
- Host aggregation of multiple board results.

These are stretch goals, not proposal commitments.
