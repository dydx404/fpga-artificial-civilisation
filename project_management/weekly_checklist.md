# Weekly Checklist

Use this checklist at the end of each week.

## Technical

- Python tests pass.
- Example simulation runs from a clean checkout.
- RTL compiles or known failures are documented.
- Interfaces changed only with documentation updates.
- Benchmarks record commit hash and configuration.

## Integration

- Each subsystem has a short status update.
- Blockers have owners.
- Fallback tier is still achievable.
- Demo path still runs.
- Next week has no more than three top priorities.

## Documentation

- Architecture notes match implementation.
- Issue backlog is updated.
- Risk register is updated.
- Screenshots or plots are saved for the report.
- Decisions are written down.
